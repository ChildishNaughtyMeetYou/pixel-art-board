# 🎨 像素画板

一个简洁美观的移动端像素画绘制工具，支持图片导入导出。

## ✨ 功能特点

- 🖼️ 画布绘制 - 点击或拖动绘制像素画
- 📐 可调尺寸 - 支持1x1到64x64的画布大小
- 🎨 丰富颜色 - 255种颜色供选择
- 📥 导入图片 - 将图片转换为像素画
- 📤 导出图片 - 保存作品为PNG格式
- 📱 移动适配 - 完美支持手机触摸操作
